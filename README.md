# Hi, I'm Ezra 👋

Developer at [Webmecanik](https://www.webmecanik.com) in Annecy, France, mostly on PHP / Symfony, API Platform and Vue.

Before code I was a psychomotor therapist working with people with disabilities. That background is why accessibility runs through my side projects: software should work for the people who usually get left out.

## Projects

- 🧩 **[Picto Planning](https://picto.strikwerda.fr)**: a free visual-schedule builder for autistic, ADHD and AAC users, with 11,500+ ARASAAC pictograms, in English, French and Dutch. Vue 3, TypeScript, FastAPI.
- 🎮 **[pixel-dungeon](https://github.com/Adrew-Kirts/pixel-dungeon)**: a 25-second one-button pixel dungeon that doubles as my portfolio, plus a 2-minute hard mode with a replay-verified leaderboard. Play it at [strikwerda.fr](https://strikwerda.fr).
- ⚡ **[ha-capfile](https://github.com/Adrew-Kirts/ha-capfile)**: Home Assistant integration for Capfile, bringing Linky electricity data with up to 3 years of history into the Energy dashboard. Packaged for HACS with Capfile's permission.
- 🧠 **[Sensory-profile-report](https://github.com/Adrew-Kirts/Sensory-profile-report)**: a Symfony app that scores Sensory Profile 2 questionnaires and generates the report.
